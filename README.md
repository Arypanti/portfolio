# 💼 Portfólio | Ariany Pantaleão

Bem-vindo(a) ao meu portfólio profissional! 👋

Este projeto foi desenvolvido para apresentar minha trajetória profissional, habilidades e projetos na área de tecnologia.

## 🚀 Sobre o projeto

Um portfólio pessoal desenvolvido para reunir informações sobre minha experiência profissional, formação, competências e projetos desenvolvidos.

O objetivo é demonstrar minha evolução na área de tecnologia através de projetos práticos e soluções desenvolvidas durante minha jornada de aprendizado.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## 💻 Projetos apresentados

### 🛒 Sistema Pimenta Flor

Sistema desenvolvido para auxiliar na gestão de uma pequena loja.

Principais funcionalidades:

- Controle de produtos
- Controle de estoque
- Registro de vendas
- Histórico de vendas
- Controle de pendências de clientes
- Relatórios

### 🎮 Jogo da Forca

Jogo interativo desenvolvido utilizando JavaScript.

O projeto possui funcionalidades como:

- Interação com o usuário
- Validação de letras
- Controle de tentativas
- Atualização dinâmica da interface
