01 — A IDEIA

Mais do que uma tela bonita: uma solução para organizar a operação

O Pimenta Flor foi desenvolvido com o objetivo de transformar rotinas de gestão em processos mais organizados e centralizados.

A aplicação reúne diferentes áreas da operação, permitindo acompanhar vendas, produtos, estoque, clientes, pendências e relatórios através de uma interface única.

Necessidade

Informações espalhadas dificultam o controle

Vendas, produtos, estoque e valores a receber precisam ser acompanhados de forma organizada para facilitar a rotina e reduzir retrabalho.

Solução

Uma aplicação para concentrar as informações

O sistema reúne os principais processos em um só lugar, com telas específicas para operação, acompanhamento financeiro e geração de relatórios.

02 — FUNCIONALIDADES

O que o sistema oferece

🛒

Gestão de vendas

Carrinho de compras, seleção de clientes, múltiplos produtos, quantidades, formas de pagamento e finalização da venda.

📦

Controle de estoque

Cadastro de produtos, acompanhamento de quantidades, identificação de estoque baixo e produtos zerados.

💰

Controle financeiro

Registro de vendas pendentes, valores pagos, saldos restantes e acompanhamento de valores a receber.

👥

Clientes e pendências

Organização de clientes e acompanhamento detalhado das pendências, parcelas, pagamentos e valores restantes.

📊

Histórico de vendas

Consulta de vendas com filtros por cliente, período, pagamento, total e detalhes dos itens.

📄

Relatórios

Indicadores da operação e exportação de informações em PDF para facilitar acompanhamento e consulta.

Arquitetura do projeto

Do banco de dados à interface

O projeto integra uma aplicação web desenvolvida com Node.js e Express a um banco de dados SQLite, utilizando JavaScript para comunicação entre interface e backend e HTML/CSS para construção da experiência visual.

Frontend HTML5, CSS3 e JavaScript para as telas e interações.
Backend Node.js + Express para rotas e regras da aplicação.
Dados SQLite para armazenamento e consulta das informações.
